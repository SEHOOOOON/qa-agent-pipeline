# Agent 1 (요구사항 정제기) 출력 패키지 샘플
## 1. 입력 수준
- Level: Level 2 (단편적 기능 정의)
- 판단 이유: 기능명(운전모드 변경)은 있으나 색상, 에러 시 UI, 타 관제점 연동 조건이 누락됨.

## 5. 중앙제어 도메인 리스크
- 운전 모드: FAN/DRY 모드 시 설정온도 변경이 차단되어야 함.
- 통신: 통신 끊김 시 UI 회색 처리 및 제어 차단 필요.

## 9. Agent 2 전달 패키지
- **관제점별 독립 검증 필요성 (Atomic):** 운전모드, 설정온도, Lock, 온라인 각각 동작 확인.
- **통합 검증 필요성 (Integration/E2E):** 사용자가 여러 관제점(난방+24도+Lock)을 한 번에 세팅하고 [적용] 버튼을 누를 때, UI와 통신 레지스터가 100% 동기화되는지 정합성 확인 필수.
- **통합 검증 대상 조합:** {mode: HEAT, setTemp: 24, locked: true, online: true}
- **Pass/Fail 기준으로 사용하면 안 되는 항목:** 기획서에 명시되지 않은 '알람 아이콘의 배경색'은 추측하여 Assert 기준에 넣지 말 것.
