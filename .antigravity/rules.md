# QA 프로젝트 자동 인지 규칙
이 규칙은 industrial-qa 프로젝트(포트폴리오) 작업 시 에이전트가 가장 먼저 인지해야 하는 기본 배경지식입니다.

- **컨텍스트 강제 인지**: 별도의 지시가 없더라도 대화 시작 시 가장 먼저 프로젝트 내의 'README.md' 문서를 읽어 프로젝트 구조를 파악하세요.
- **Agent 4개의 핵심 역할**: 작업 시 다음 4가지 Agent 역할을 항상 기본 배경지식으로 인지하고 대화에 임하세요.
  - **Agent 1**: 요구사항 정제
  - **Agent 2**: TC(테스트 케이스) 설계
  - **Agent 3**: 자동화 실행 (Playwright/Pytest)
  - **Agent 4**: 결과 원인 분석 및 보고 (Notion/Slack)
