중앙제어 품질 기준을 내장한
Multi-Agent QA Workflow

반복되는 회귀 테스트의 휴먼 에러를 줄이고, 사람은 더 복잡한 이슈를 찾는 데 집중하기 위해 자동화를 기획했습니다. 하지만 AI에게 온전히 맡길 경우 상황을 임의로 추측하여 신뢰도가 떨어지는 문제가 있었습니다. 이를 해결하기 위해, 제 실무 QA 기준을 체크포인트로 적용하여 AI가 동일한 품질 기준으로 테스트를 수행하도록 구조화했습니다.

품질 기준 보기반려·수정 사례구현 영상

※ 시뮬레이터의 Agent·CI/CD 화면은 Workflow Demo이며, 실제 결과는 Pytest Report와 실행 결과 JSON을 기준으로 합니다.

프로젝트 기획 의도 V1
  1. 01
    일관된 테스트 기준 적용동일한 품질 기준으로 반복 검증하여 휴먼 에러를 줄입니다.
  2. 02
    반복 작업의 자동화요구사항 분석부터 결과 보고까지의 회귀 파이프라인을 구성합니다.
  3. 03
    탐색적 테스트에 집중반복 업무를 자동화하고 복잡한 결함 탐색에 시간을 집중합니다.
1 프로젝트 배경

일관된 품질 판단 기준의 필요성

검토자의 경험에 따라 달라지는 테스트 범위와 AI가 근거 없는 기대값을 만드는 문제를 구조적으로 개선하고자 했습니다.

!

반복해서 마주한 문제

  • 동일 요구사항도 담당자에 따라 테스트 범위가 달라짐
  • AI가 요구사항에 없는 기대값을 확정함
  • 모호한 TC가 자동화와 보고 단계까지 전파됨
✓

프로젝트의 접근 방식

  • QA 판단 기준을 3단계 품질 기준으로 구조화
  • Agent가 정해진 형식으로 결과물을 생성
  • Checkpoint가 동일한 기준으로 결과 품질을 확인
핵심 목표AI가 많은 테스트케이스를 만드는 것이 아니라, 요구사항부터 실행 결과까지 동일한 품질 기준을 유지하고 근거 없는 판단이 다음 단계로 넘어가지 않도록 하는 것입니다.

경험에 머물던 QA 판단 기준을 공통 QA, 중앙제어 도메인, 기능별 품질 기준으로 구분하고 반복 적용할 수 있도록 정리했습니다.

AI 결과에 대한 품질 통제

AI가 만든 결과를 그대로 사용하지 않고 근거, 독립성, 판정 가능성과 추적성을 검토해 승인된 결과만 다음 단계로 전달했습니다.

실행 결과 기반 의사결정

자동화 상태와 실패 원인을 분리하고, Report와 결과 데이터의 정합성을 확인해 릴리즈 권고까지 연결했습니다.

핵심 의미AI를 많이 사용하는 것보다, 동일한 QA 기준이 요구사항부터 실행 결과와 보고까지 유지되도록 만드는 것이 이 프로젝트의 핵심입니다.
10 현재 한계점

시스템 구조적 한계점

V1 단계에서 마주한 현장 제약과 실무 유지보수 관점에서의 개선 포인트를 정리했습니다.

01

기획서 미정의 항목의 판단 불가

기획서에 누락되거나 모호한 정책(예: 알람 발생 시 카드 UI 색상)은 AI나 자동화가 판단할 수 없어 사람의 최종 확인이 필수적입니다.

02

UI 변경 및 Flaky Test 제약

웹 UI 요소 셀렉터 변경 시 스크립트 수정 공수가 발생하며, 네트워크/비동기 타이밍에 따른 간헐적 실패(Flaky Test) 관리가 필요합니다.

03

가상 환경과 실장비의 차이

실제 물리적 에어컨 장비나 통신 패킷 손실 등 현장의 특수 물리 예외까지는 웹 시뮬레이터 환경에서 전수 재현하기 어렵습니다.

04

파이프라인 분석 대기시간

4개 Agent의 연속적인 검토 및 QA Checkpoint 심사 과정이 추가되어 단순 스크립트 실행보다 응답 대기시간이 길어집니다.

11 향후 로드맵

고도화 및 확장 계획

Flaky Test 격리, Self-Healing 셀렉터, CI/CD 연동을 중심으로 실무 자동화 파이프라인을 고도화합니다.

Flaky Test 자동 격리 및 Retry 로직 도입

비동기 지연으로 인한 간헐적 실패(Flaky Test)를 자동 감지하여 3회 재시도(Retry)하고, 신뢰성 낮은 테스트를 자동 격리 관리합니다.

Self-Healing (셀렉터 자동 복구) 스크립트

UI 셀렉터가 변경되더라도 AI가 대체 요소를 탐색하여 자동화 스크립트 파손을 방지하고 유지보수 공수를 줄이는 것을 목표로 합니다.

GitHub Actions CI/CD 파이프라인 연동

개발팀 코드 PR/커밋 발생 시 Multi-Agent 회귀 테스트를 자동으로 구동하고 결과 리포트를 Slack으로 자동 전송합니다.

통신 프로토콜 패킷 데이터 검증 자동화

UI 화면 검증을 넘어 Modbus / MQTT 통신 레지스터 패킷 데이터까지 대조하여 시스템 무결성을 자동 검증합니다.

12 주요 산출물

소스코드 및 실행 증거

구현 코드, 최신 통합 Run 결과와 요구사항-테스트 추적 자료를 확인할 수 있습니다.
